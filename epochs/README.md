# ЭПОХИ — Последний правитель

Standalone browser strategy game. Open `index.html` in a modern browser; no build step or external dependencies are required.

## Gameplay
- Develop food, timber, stone, gold and research.
- Build farms, sawmills, quarries, markets, academies, barracks and walls.
- Expand into neutral regions, negotiate with the rival kingdom of Veyr, or wage war.
- Unlock technologies, respond to events and advance through seasons.
- Progress is saved locally in the browser.

## Project files
- `index.html` — app markup
- `style.css` — responsive interface
- `game-loader.js` — loads the compressed game engine\n- `game-expansion.js` — achievements, optional objectives and the ruler's chronicle
